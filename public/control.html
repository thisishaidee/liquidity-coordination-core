Set up your NERITH workspace.

Your workspace is your team’s private operating space in NERITH. It brings your agents, business wallets, liquidity requests, permissions and operating limits together, so your team can coordinate funding in one place. It is an organisation boundary, not a wallet or a place where funds are held.

Telegram permissions

Newly linked Telegram accounts start with Operator access: one account can create liquidity requests, review prepared operations, and manage its own requests. Google Authenticator is required to approve or reject a request created by that same account. Requester is a legacy create-only permission; upgrade it to Operator to use one account for the full workflow. Viewers can only read business information. No Telegram role can sign transactions or move funds.

2. Register business wallets

Register public Solana addresses only. NERITH reads confirmed SOL and USDC balances; it never asks for a seed phrase or private key.

Operating wallet

Holds business assets used to cover authorized agent liquidity needs. Agent access still depends on its treasury permissions.

Swap.io x402 payment wallet

A separate business wallet that holds USDC only for paying Swap.io API access fees. It is not counted as operating liquidity and does not authorize agent spending.

Keep this address separate from every operating wallet. The conversion API currently requires a fresh balance of at least 0.01 USDC as a reserve check; the actual x402 charge is determined by Swap.io's 402 payment request. Registering a wallet does not move funds or grant signing authority.

How setup works

Start with the workspace. Telegram comes after your team and operating setup are in place.

1
Create the workspace

Enter a workspace name and your first agent. Save the one-time agent API key when it appears.

2
Register your operating wallet

Add the public Solana wallet address your business uses for operating liquidity. Never enter a seed phrase or private key.

3
Set up agents and controls

Review agent access, connect the wallets your business uses, and set daily API payment limits where needed.

4
Connect Telegram (optional)

Create a bot with @BotFather, configure its Worker secrets and webhook, then issue private invitations to your team.

What a workspace means
A workspace keeps one team’s agents, wallets, requests and permissions together. It is not a wallet and does not hold funds. Telegram is simply another interface to the same workspace. Operators can create requests and review prepared operations; sensitive self-approval requires Google Authenticator. Telegram cannot sign, broadcast or move funds.

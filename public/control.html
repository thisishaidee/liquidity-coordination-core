Telegram permissions

Every linked Telegram account starts as a viewer. Requesters can create liquidity requests. Approvers can create requests and independently review prepared operations. Viewers can only read business information. A requester cannot approve their own request. No Telegram role can sign transactions or move funds. A requester cannot approve their own Telegram-originated request. This permission does not sign transactions or move funds.

Business wallets

Register public Solana addresses only. NERITH reads confirmed SOL and USDC balances; it never asks for a seed phrase or private key.

Operating wallet

Holds business assets used to cover authorized agent liquidity needs. Agent access still depends on its treasury permissions.

Swap.io x402 payment wallet

A separate business wallet that holds USDC only for paying Swap.io API access fees. It is not counted as operating liquidity and does not authorize agent spending.

Keep this address separate from every operating wallet. The conversion API currently requires a fresh balance of at least 0.01 USDC as a reserve check; the actual x402 charge is determined by Swap.io's 402 payment request. Registering a wallet does not move funds or grant signing authority.

Before you begin

A few account-owned steps are required before the bot can go live.

1
Create the Telegram bot

Open @BotFather, send /newbot and copy the token it gives you.

2
Add Worker secrets

In Cloudflare → Workers & Pages → liquidity-coordination-api → Settings → Variables and Secrets, add ADMIN_BOOTSTRAP_TOKEN, TELEGRAM_BOT_TOKEN and TELEGRAM_WEBHOOK_SECRET as secrets.

3
Create your workspace

Use the form with the same admin token configured in Cloudflare. The first agent key is only shown once.

4
Link your private Telegram

Configure the webhook, create an invitation and open it from your own private Telegram account. Group chats are not accepted.

Security boundary
Requesters can create liquidity requests. Approvers can create requests and approve or reject requests submitted by someone else. Viewers can only read business information. Self-approval is blocked. Telegram never stores wallet keys and cannot sign, broadcast or transfer funds. Decisions are recorded against the exact operation.

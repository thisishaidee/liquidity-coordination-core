Before you begin

A few account-owned steps are required before the bot can go live.

1
Create the Telegram bot

Open @BotFather, send /newbot and copy the token it gives you.

2
Add Worker secrets

In Cloudflare → Workers & Pages → liquidity-coordination-api → Settings → Variables and Secrets, add ADMIN_BOOTSTRAP_TOKEN, TELEGRAM_BOT_TOKEN and TELEGRAM_WEBHOOK_SECRET as secrets.

3
Create your workspace

Use the form with the same admin token configured in Cloudflare. The first agent key is only shown once.

4
Link your private Telegram

Configure the webhook, create an invitation and open it from your own private Telegram account. Group chats are not accepted.

Security boundary
Telegram is read-only. It can report liquidity, forecasts, agents and operations, but cannot sign transactions, move funds or approve spending. Your admin token is held in this page's memory only.
